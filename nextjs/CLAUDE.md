# ai-tools-for-journalists app

A Next app that renders every Markdown file under the repo's `_context/` (one level up) at the same path, plus `/capture`, `/live`, and `/print`. See the repo `README.md`. This repo is public: keep keys in `.env.local` (gitignored) and keep anything private out of `_context/` and `_media/`.
